# 🔷 QLines

**QLines** - это минималистичная интерактивная программа-игрушка, редактор узоров на холсте с узловой сеткой. По факту, я бы назвал его "Редактором тетрадного листа". Проект позволяет создавать все возможные узоры, сохранять собственные узоры в библиотеку и управлять ими.

❕Чтобы установить и сразу попробовать программу перейдите в папку `release` и скачайте `QLines v.1.1.exe` (14.4 МБ). Вы также можете скачать `patterns.json` в котором находятся 15 заготовленных ("официальных") узоров. Оба файла должны лежать рядом, в одном каталоге (папке).

---

## ✨ Основные возможности

* **Интерактивное векторное рисование:** построение узоров по узлам координатной сетки с визуальным предпросмотром линий и автоудалением единичных соединений.
* **Выделение и трансформация:**
  * Выделение фрагментов рамкой и их свободное перемещение по сетке.
  * Поворот выделенной области на 90° по часовой (`R`) и против часовой стрелки (`Shift+R`).
  * Зеркальное отражение выделенного фрагмента по горизонтали (`G`) и вертикали (`Shift+G`).
* **Буфер обмена и многократная вставка:** копирование (`C`) и вырезание (`X`) объектов с последующей быстрой простановкой копий на холсте.
* **История действий:** поддержка отмены (`Ctrl+Z`) и повтора (`Ctrl+Y`) с полной сохранностью состояний холста.
* **Хранилище узоров:**
  * Сохранение собственных узоров с указанием названия и автора (`Ctrl+S`).
  * Каталог узоров (`Ctrl+A`) с поиском, предпросмотром, редактированием, удалением и загрузкой.
* **Навигация и масштаб:**
  * Бесконечный холст с панорамированием через клавиши `WASD` или зажатие кнопки мыши.
  * Плавное масштабирование с фокусом на курсоре.
  * Быстрый переход к точным координатам (X, Y) (`Ctrl+F`).
* **Настраиваемый интерфейс:** модальные окна управления и переключаемая строка контекстных подсказок (`Q`).

## 🎮 Управление и горячие клавиши

### Навигация и камера

| Клавиша / Действие | Функция |
| :--- | :--- |
| **W / A / S / D** | Перемещение камеры по холсту |
| **Зажатие СКМ или ПКМ** | Перетаскивание холста мышью |
| **Колесо мыши** | Масштабирование (приближение / отдаление) |
| **Ctrl + F** | Открыть окно перехода к координатам (X, Y) |

### Рисование и общие команды

| Клавиша / Действие | Функция |
| :--- | :--- |
| **ЛКМ** (в режиме рисования) | Провести линию от узла к узлу / Удалить линию при клике по ней |
| **Ctrl + Z** | Отменить последнее действие (Undo) |
| **Ctrl + Y** | Повторить отмененное действие (Redo) |
| **T** | Полностью очистить холст |
| **Q** | Показать / скрыть контекстные подсказки клавиш |
| **Esc** | Сбросить текущий режим / Закрыть модальное окно |

### Выделение и трансформации

| Клавиша / Действие | Функция |
| :--- | :--- |
| **E** | Включить режим выделения |
| **ЛКМ (зажать и потянуть)** | Выделить область рамкой |
| **ЛКМ (внутри выделения)** | Переместить выделенный фрагмент по сетке |
| **C** | Скопировать выделенное и перейти в режим вставки |
| **X** | Вырезать выделенное и перейти в режим вставки |
| **R** | Повернуть выделенное на 90° по часовой стрелке |
| **Shift + R** | Повернуть выделенное на 90° против часовой стрелки |
| **G** | Отзеркалить выделенное по горизонтали (слева направо) |
| **Shift + G** | Отзеркалить выделенное по вертикали (сверху вниз) |

### Вставка и библиотека узоров

| Клавиша / Действие | Функция |
| :--- | :--- |
| **ЛКМ** (в режиме вставки) | Разместить скопированный узор на холсте (многократная вставка) |
| **Ctrl + S** | Сохранить текущий узор в хранилище |
| **Ctrl + A** | Открыть хранилище узоров (загрузка, поиск, редактирование) |
| **Tab** | Переключение между полями ввода в модальных окнах |
| **Enter** | Подтвердить действие в модальном окне |

Новый проект. Программа-игрушка. Python. Бесконечный холст в клеточку, который можно приближать/отдалять. На каждом пересечении можно нажать и потянуть - это создаст линию, отпустить и линия зафиксируется на пересечении. Каждая линия имеет по точке на концах.

Один раз нажать левой кнопкой по точке или линии удаляет её.

Внутреннее хранилище узоров.
Отдельный файл "patterns", в котором все сохранённые узоры. Программа сама создаёт его, при первом сохранённом узоре. При запуске она проверяет наличие этого файла. Для запуска программы наличие этого файла неважно.

Комбинация "Ctrl+S" - сохраняет узор. Открывает прямоугольное окно, название "Сохранить узор". В левой части окна есть окошко с частью холста от нулевого 10 узлов во все стороны, изображение 1:1 с узом "0, 0" по центру. В правой части можно именовать узор, по умолчанию в поле ввода уже есть имя "pattern_1", если такой узор в хранилище уже есть, то по умолчанию "pattern_2" и так далее, имена не могут повторяться, о чём будет предупреждать маленький красный текст под полем имени, который появляется если ввести недопустимое имя. Также можно указать автора - необязательно. В правом нижнем углу кнопки "Отмена" и "Сохранить".

Комбинация "Ctrl+A" - открывает окно с узорами, название "Хранилище узоров". В окне узоры выложены плитками, 4 штуки в ширину, с прокруткой вниз. Плитка чуть вытянутая по вертикали, в ней есть картинка 1:1 узора (картинка создаётся при сохранении), под картинкой имя (200, 200, 200), под именем автор (120, 130, 150). В правом, верхнем углу есть поиск по именам и авторам узоров. В правом нижнем углу кнопки "Отмена", "Вставить" и "Загрузить". Выбрав узор его можно вставить в текущий холст или загрузить весь выбранный холст, текущий исчезает.

================================================================
Комбинация "Ctrl+Z" - отменить последнее действие.

Комбинация "Ctrl+Y" - повторить отмененное действие.

Комбинация "M" - позволяет выделить область, в которой берёт все точки и линии (только те, что имеют две точки), и переместить их в другое место, все выделенные линии и точки белого цвета.

В "Хранилище узоров" добавь кнопку "Удалить", перед "Отмена".

В "Хронилище узоров" должна быть сортировка, по именам. Идут сначала цифры от нуля, потом a-z, потом а-я.

В "Хранилище узоров" добавь кнопку "Изменить", между "Удалить" и "Отмена". Она откроет обычное окно "Сохранить узор" поверх первого окна.

Работа с текстом (ввод, редактирование, выделение, перемешение) работает странно. Нет курсора, нельзя поставить его в нужное место, нельзя выделить текст частично и полностью, нельзя скопировать и вставить.

Комбинация "Ctrl+F" - открывает окно "Перемещение", в нём две строки, примерно "x=[]" и "y=[]", где скобки это поле ввода для координат, и кнопка "Переместиться".
