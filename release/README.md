
# 🔷 QLines

**QLines** - это минималистичная интерактивная программа-игрушка и редактор векторных узоров на бесконечном холсте с узловой сеткой. Проект позволяет создавать геометрические фигуры, исследовать симметрию, сохранять собственные узоры в библиотеку и управлять ими.

❕Чтобы установить и сразу попробовать программу перейдите в папку `release` и скачайте `QLines v.1.0.exe`. Вы также можете скачать `patterns.json` в котором находятся 15 заготовленных ("официальных") узоров. Оба файла должны лежать рядом, в одном каталоге (папке).
---

## ✨ Основные возможности

* 📐 **Бесконечный холст и сетка**: Свободное перемещение по координатной плоскости и масштабирование без ограничений.
* ✍️ **Узловое рисование**: Линии автоматически привязываются к узлам сетки для создания точных геометрических форм.
* 💾 **Хранилище узоров (Библиотека)**: Сохранение созданных узоров с названием и автором, их поиск, редактирование и предварительный просмотр.
* 📋 **Выделение, вставка и перемещение**:
  * Выделение фрагментов рисунка и копирование.
  * Перемещение готовых групп линий по холсту.
* 📍 **Быстрый переход по координатам (`Ctrl + F`)**: Мгновенная навигация к любой точке плоскости по $X$ и $Y$.
* ↩️ **История действий (Undo / Redo)**: Полная поддержка отмены (`Ctrl + Z`) и повтора (`Ctrl + Y`) действий.
* 🔍 **Умный зум и центрирование**: Масштабирование относительно курсора мыши и автоцентрирование камеры при загрузке узоров.

## 🎮 Управление и горячие клавиши

### 🖱️ Мышь
| Действие | Описание |
| :--- | :--- |
| **ЛКМ** | Рисование линии (между узлами) / Выбор / Подтверждение |
| **Зажатие ЛКМ на линии/узле** | Удаление линии или связанного узла |
| **Зажатие ПКМ / СКМ** | Перемещение холста (Pan) |
| **Колёсико мыши** | Масштабирование (Zoom) |

### ⌨️ Клавиатура
| Сочетание клавиш | Функция |
| :--- | :--- |
| **W / A / S / D** | Навигация камерой по холсту |
| **M** | Переход в режим **Перемещения** выделенного фрагмента |
| **C** | Переход в режим **Выделения / Копирования** |
| **R** | Очистить текущий холст |
| **Ctrl + S** | Сохранить текущий узор в Хранилище |
| **Ctrl + A** | Открыть **Хранилище узоров** (Библиотеку) |
| **Ctrl + F** | Открыть окно **«Перемещение»** (переход по X, Y) |
| **Ctrl + Z** | Отменить последнее действие (Undo) |
| **Ctrl + Y** | Повторить отмененное действие (Redo) |
| **Esc** | Сбросить текущий режим / Закрыть модальное окно |

## 📁 Структура проекта

```text
QLines/
├── main.py          # Главный цикл приложения, UI и обработка событий
├── config.py        # Настройки цветов, шрифтов и констант
├── widgets.py       # Кастомные UI-виджеты (InputField, кнопки)
├── geometry.py      # Преобразования координат, работа с сеткой и превью
├── storage.py       # Логика сохранения и загрузки JSON-файлов узоров
├── make_icon.py     # Скрипт генерации иконки приложения (.ico)
├── icon.ico         # Иконка программы
└── patterns.json    # Локальная база данных сохраненных узоров
```

**QLines** был написан с помощью ИИ. Основные запросы реализации:
```text
Новый проект. Программа-игрушка. Python. Бесконечный холст в клеточку, который можно приближать/отдалять. На каждом пересечении можно нажать и потянуть - это создаст линию, отпустить и линия зафиксируется на пересечении. Каждая линия имеет по точке на концах.

Один раз нажать левой кнопкой по точке или линии удаляет её.
Кнопка "R" - очистить всё.
Кнопка "S" - позволяет выделить область, в которой берёт все точки и линии (только те, что имеют две точки), можно вставить в другом месте, и видно силуэт того, что будет вставляться.

================================================================
Внутреннее хранилище узоров.
Отдельный файл "patterns", в котором все сохранённые узоры. Программа сама создаёт его, при первом сохранённом узоре. При запуске она проверяет наличие этого файла. Для запуска программы наличие этого файла неважно.

Комбинация "Ctrl+S" - сохраняет узор. Открывает прямоугольное окно, название "Сохранить узор". В левой части окна есть окошко с частью холста от нулевого 10 узлов во все стороны, изображение 1:1 с узом "0, 0" по центру. В правой части можно именовать узор, по умолчанию в поле ввода уже есть имя "pattern_1", если такой узор в хранилище уже есть, то по умолчанию "pattern_2" и так далее, имена не могут повторяться, о чём будет предупреждать маленький красный текст под полем имени, который появляется если ввести недопустимое имя. Также можно указать автора - необязательно. В правом нижнем углу кнопки "Отмена" и "Сохранить".

Комбинация "Ctrl+A" - открывает окно с узорами, название "Хранилище узоров". В окне узоры выложены плитками, 4 штуки в ширину, с прокруткой вниз. Плитка чуть вытянутая по вертикали, в ней есть картинка 1:1 узора (картинка создаётся при сохранении), под картинкой имя (200, 200, 200), под именем автор (120, 130, 150). В правом, верхнем углу есть поиск по именам и авторам узоров. В правом нижнем углу кнопки "Отмена", "Вставить" и "Загрузить". Выбрав узор его можно вставить в текущий холст или загрузить весь выбранный холст, текущий исчезает.

================================================================
Комбинация "Ctrl+Z" - отменить последнее действие.

Комбинация "Ctrl+Y" - повторить отмененное действие.

Комбинация "M" - позволяет выделить область, в которой берёт все точки и линии (только те, что имеют две точки), и переместить их в другое место, все выделенные линии и точки белого цвета.

В "Хранилище узоров" добавь кнопку "Удалить", перед "Отмена".

В "Хронилище узоров" должна быть сортировка, по именам. Идут сначала цифры от нуля, потом a-z, потом а-я.

В "Хранилище узоров" добавь кнопку "Изменить", между "Удалить" и "Отмена". Она откроет обычное окно "Сохранить узор" поверх первого окна.

Работа с текстом (ввод, редактирование, выделение, перемешение) работает странно. Нет курсора, нельзя поставить его в нужное место, нельзя выделить текст частично и полностью, нельзя скопировать и вставить.

Комбинация "Ctrl+F" - открывает окно "Перемещение", в нём две строки, примерно "x=[]" и "y=[]", где скобки это поле ввода для координат, и кнопка "Переместиться".
```
